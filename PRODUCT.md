# NEXORA
## Platform
Web, portfolio demonstration for Kwork. The user-supplied SPEC.md is authoritative.
## Stack
Delegated by the brief: React + TypeScript + Vite, Three.js, Leaflet, localStorage and IndexedDB. Static SPA, no backend, no paid API requirement. Hosting chosen later.
## Product truth
Seven routes: home, buy/rent catalogue, property, favourites/comparison, account, publishing wizard, about. Twelve fictional listings, five cities, four types, nine sale and three rental properties. No real enquiries or protected authentication. User listings and photos stay in this browser. Demo notices explicit. Russian and English; USD/EUR/AED fixed illustrative rates.
## Acceptance
SPEC.md sections 17–20. Deliver source, README, runnable build, functional user journeys, mobile layouts, keyboard support and reduced motion.
