# NEXORA

Демонстрационная платформа международной элитной недвижимости для портфолио Kwork. Все предложения, цены и отзывы вымышлены. Реальных отправок сообщений, платежей и защищённой авторизации нет.

## Запуск

Требуется Node.js 22.12+ (проверено на Node 24), npm и современный браузер.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist`. Не открывайте `index.html` через `file://`: маршрутизация и локальные хранилища требуют HTTP/HTTPS.

## Временная публичная ссылка

В Windows PowerShell из папки проекта выполните `npm.cmd run share`. Нужны готовая папка `dist`, установленные зависимости и OpenSSH (команда `ssh`, обычно есть в Windows). Скрипт запускает отдельный сервер сборки на порту 4175 и временный туннель localhost.run, затем печатает HTTPS-ссылку. Отправьте её другим и оставьте терминал открытым. `Ctrl+C` выключает сервер и туннель. Компьютер должен оставаться включённым и подключённым к интернету, без сна. Адрес временный и может измениться при повторном запуске или ротации сервисом; актуальный адрес печатается в терминале. Доступ открыт всем, у кого есть ссылка.

Скрипт разрешает Vite только текущий адрес туннеля. SSH использует подключение без учётной записи и личных ключей; ключ сервера сохраняется в `.local/known_hosts`. Если сеть блокирует SSH, попробуйте другой сервер VPN или сеть. Cloudflare в проверенной сети не смог подключиться к порту 7844 ни через QUIC, ни через HTTP/2.

После изменения сайта сначала выполните `npm.cmd run build`. Пользовательские данные по-прежнему сохраняются отдельно в браузере каждого посетителя.

## Что реализовано

- Семь основных страниц: главная, общий каталог покупки/аренды, объект, избранное/сравнение, кабинет, мастер объявления, о проекте.
- 12 демообъектов: Dubai 4, Monaco 3, New York 2, Tokyo 2, Miami 1; девять покупок и три аренды. Четыре типа недвижимости и по четыре согласованных AI-ракурса каждого объекта.
- Интерактивная Земля Three.js с пятью городами и управлением камерой. Мобильный статичный глобус, видео при отказе WebGL и статичный запасной вариант.
- Карта Leaflet/OpenStreetMap без API-ключа. Список и маркеры используют общий результат фильтров. Мобильное переключение карты/списка и панель фильтров.
- Фильтры применяются кнопкой, сохраняются в URL; шесть режимов сортировки. Ценовые фильтры вводятся в выбранной валюте.
- Галерея со свайпами, стрелками и Escape; избранное; сравнение максимум двух объектов одного типа сделки с заменой выбранного.
- Демовход с именем/email без пароля и быстрый Demo User. Заявка по объекту требует демосессии; контактная форма на главной доступна гостям. Подтверждение честно сообщает, что ничего не отправлено.
- Калькулятор аннуитета с нулевой ставкой и проверкой диапазонов. Первоначальный взнос вводится как процент цены.
- Создание, редактирование и удаление собственных объявлений. Четыре шага, загрузка/drag-and-drop JPEG/PNG/WebP, максимум 10 файлов до 5 МБ каждый, оптимизация до 1600 px, выбор обложки, предупреждение перед уходом.
- RU/EN, USD/EUR/AED, светлая/тёмная темы, сохранение настроек, системное и ручное уменьшение движения. Шрифт Space Grotesk; для кириллицы используется локальный Manrope, поскольку у Space Grotesk нет кириллического набора.

## Данные и ограничения демоверсии

`localStorage` хранит настройки, избранное, сравнение и демосессию под ключами `nexora.*.v1`. Объявления и оптимизированные изображения находятся в IndexedDB `nexora`, хранилище `listings`. Большие изображения не записываются в localStorage.

Данные принадлежат браузеру/профилю, не синхронизируются, не защищаются аккаунтом и пропадают при очистке данных сайта. Неверный JSON и недоступность хранилища не должны обрушать приложение. При ошибке записи объявления показывается сообщение, успешная публикация не имитируется.

Для собственных объявлений нужны английское и русское описания. Координаты назначаются приблизительно по выбранному городу; все локации отмечены как демонстрационные. Не вводите конфиденциальные сведения.

Курсы фиксированы в `src/model.ts`: 1 USD = 0.92 EUR = 3.6725 AED. Это не рыночные котировки. Калькулятор не учитывает налоги, комиссии и правила кредитования конкретных стран.

Карты требуют интернета. При недоступных тайлах остаются список объектов, маркеры и сообщение об ошибке. Все фотографии, текстура Земли и шрифты локальные. Источники и лицензии перечислены в `ASSETS.md` и на странице `/asset-credits.html`.

```text
src/

  storage.ts        устойчивое чтение localStorage, IndexedDB, изображения
  Globe.tsx         лениво загружаемая 3D-сцена

```

## Проверка

```sh
npm test
npm run build
```

Для браузерных сценариев нужен установленный Microsoft Edge. Сначала запустите `npm run dev -- --port 5174`, затем в другом терминале:

```sh
node scripts/e2e.mjs
```

Другой сервер задаётся переменной `NEXORA_URL`. Сценарий использует отдельный временный профиль браузера, не затрагивает ваши реальные данные и сохраняет отчёт/снимки в `qa/`. Подробности проверки: `QA.md`.

## Публикация позже

Хостинг намеренно не выбран. Загрузите содержимое `dist` на статический HTTPS-хостинг и настройте SPA fallback: все неизвестные пути должны отдавать `index.html`. Пример для Nginx:

```nginx
location / { try_files $uri $uri/ /index.html; }
```

В `public/_redirects` есть правило для хостингов, понимающих этот формат. Файлы `/media/*` и `/assets/*` должны раздаваться напрямую с корректным Content-Type. Для публичного посещаемого проекта перед запуском проверьте политику использования OSM-тайлов и при необходимости выберите подходящего поставщика; URL задаётся в `src/Map.tsx`.

Проект не содержит ключей, платных API или привязки к хостинг-провайдеру. Добавление настоящей авторизации, отправки сообщений, серверного каталога и платежей потребует отдельной серверной реализации.
